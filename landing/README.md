# Landing de GastroManager

Página de presentación estática (`index.html`, `styles.css`, `app.js`), sin build. Se abre directo en el navegador.

Los módulos con la etiqueta **Pronto** y las filas **Próximamente** de la tabla comparativa todavía no
están en el sistema: al terminar cada uno, sacar la etiqueta (`<span class="soon-tag">…</span>` o `ct-soon`).
No marcar como "Incluido" nada que el sistema no haga.
